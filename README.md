Практическая работа №6
Задание: определить номер билета и понять, счастливый он или нет. 
Основное условие задания - использование только switch/case для проверки билета.

Программа начинает работу с настройки интерфейса: очищает экран, меняет цвет фона на темно-синий, цвет текста — на белый, а также задает программное имя в заголовке консоли. Далее происходит объявление целочисленных переменных типа int: number, digit1–digit6, SumFirst и SumLast.
Программа приветствует пользователя и запрашивает ввод шестизначного номера билета. После ввода запускается проверка, где в случае, если номер не является шестизначным, консоль выводит сообщение о вводе недопустимого числа пользователя. В противном случае программа переходит к извлечению разрядов номера билета (единицы, десятки, сотни и так далее) с помощью математических операций и последовательно сохраняет их в переменные от digit6 до digit1.
Затем программа складывает три первых и три последних разряда числа, сохраняя результаты в переменные SumFirst и SumLast. Используя конструкцию switch, приложение проверяет эти значения на равенство. Если они равны, на экран выводится сообщение о том, что билет выигрышный, а в противном случае выводится сообщение о проигрышном билете.
В программе реализована безопасная обработка исключений с помощью блоков try-catch. Исключение FormatException перехватывает конкретные ошибки ввода — например, если пользователь введет буквы вместо цифр, текст консоли окрасится в красный цвет и выведется сообщение о том, что входная строка имела неправильный формат. В свою очередь, блок общего типа Exception обрабатывает любые другие системные ошибки, которые не были пойманы предыдущим блоком, включая ошибку OverflowException, возникающую при вводе слишком длинного числа, выходящего за числовые границы диапазона Int32.
В самом конце программа ожидает нажатия любой клавиши через команду Console.ReadKey(), чтобы окно консоли не закрылось сразу после завершения расчетов.
